# Life Expectancy and Economic Indicators Analysis
## Project Overview
This project explores global life expectancy trends in relation to economic factors such as GDP per capita, health expenditure, and employment rates. Using cleaned datasets covering 175 countries from 2000 to 2015, this analysis aims to identify patterns, regional disparities, and potential influences of healthcare investment on life expectancy.

## Project Structure
The repository is organized into the following directories:

- Datasets/ – Contains the cleaned datasets used for analysis.
- Notebooks/ – Jupyter notebooks for data exploration, visualization, and modeling.
- reports/ – Summary reports and findings.
- src/ – Scripts for data processing and analysis.
- tests/ – Unit tests to validate data transformations.

## Dataset Summary
- Descriptive_Statistics_All_Dfs/ – Combined descriptive statistics for all datasets.
- Descriptive_Statistics_by_Region/ – Summarized statistics for five global regions.
- EDA_Datasets/ – Includes exploratory analysis by income class and top/bottom GDP countries.
- World_Regions/ – Datasets segmented by regions and sub-regions for comparative analysis.

## Key Analysis Areas
- Relationship between GDP per capita and life expectancy.
- Impact of healthcare expenditure on health outcomes.
- Disparities across income classes and geographic regions.
- Trends in adult and child mortality over time.
