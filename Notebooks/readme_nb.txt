This folder contains Jupyter notebooks used throughout the Data Analytics Project. Each notebook represents a distinct stage in the data analysis process. 
1.  Below is a summary of the notebooks and their roles:

    Notebook Summaries
    
    1.1 df_tidying.ipynb

        Purpose: Focuses on cleaning and tidying the dataset, ensuring the structure adheres to tidy data principles.
        Key Tasks:
        Handling missing values.
        Renaming or reordering columns.
        Converting data types if necessary.

    1.2 df_wrangling.ipynb

        Purpose: Data wrangling tasks to prepare the dataset for analysis by transforming and reshaping it as required.
        Key Tasks:
        Merging or joining datasets.
        Feature engineering.
        Filtering or subsetting data.

    1.3 descriptive_analysis.ipynb

        Purpose: Performs descriptive statistics and provides an overview of the dataset, including measures of central tendency, dispersion, and key insights.
        Key Outputs: Summary statistics, visualizations for understanding distribution, and data overview.

    

    1.4 EDA (exploratory data analysis).ipynb

        Purpose: Conducts exploratory data analysis to identify trends, patterns, and outliers in the data.
        Key Outputs: Visualizations (scatter plots, histograms, heatmaps, etc.) and exploratory insights.

    1.5 final_analysis.ipynb

        Purpose: Consolidates the analysis and generates the final results, combining insights from exploratory and inferential analyses.
        Key Outputs: Final visualizations, summaries, and key conclusions.

   
    Notes
    The analysis progresses from cleaning and wrangling (data preparation) to descriptive and exploratory, culminating in the final analysis.
    Ensure all dependencies and libraries are installed before running these notebooks.
