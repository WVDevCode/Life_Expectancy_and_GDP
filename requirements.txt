3. Environment Management and Compatibility (Optional)
    Add version compatibility management to specify exact versions of packages you’re using (helpful to ensure code runs the same on different systems). To generate this, you can run:

    powershell:

        pip freeze > requirements.txt


4. Shell Setup for Git Commands (PowerShell Instructions)

    Navigate to your project directory:

        cd "path\to\your\project"

    Initialize a Git repository:

        git init

    Add remote repository (link your local repo to GitHub):

        git remote add origin https://github.com/username/repo.git

    Stage all files and make the first commit:

        git add .
        git commit -m "Initial commit"
        
    Push the initial commit to GitHub:

        git push -u origin main

These instructions, combined with the requirements.txt, will provide 
a full setup for your data analytics project repository on GitHub, including package dependencies and PowerShell Git commands.
